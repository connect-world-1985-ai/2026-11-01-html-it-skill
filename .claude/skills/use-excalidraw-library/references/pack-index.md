Do not paste this file into chat. Load a catalog only after the pack survives pre-flight. If no row matches (third-party product logos such as Slack/Docker/GitHub, or generic non-AWS VPC/server glyphs), the proposed set is empty: use pre-flight C (built-ins). Do not invent a pack id.
