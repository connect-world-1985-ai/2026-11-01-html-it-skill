## Image 1: snapshot versus log concept illustration

- **Prompt:** "Flat editorial illustration, warm muted palette (ivory background, slate and terracotta accents), no text, no letters, no numbers. Left side: a single paper form on a clipboard, with an eraser and smudged, overwritten fields, suggesting that only the latest version survives. Right side: a long paper ledger strip unrolling downward, with many neat lines added one under another and a pen adding a new line at the bottom, suggesting that every change is kept in order. A subtle dividing line between the two halves. Calm, friendly, suitable for a technical onboarding page. Wide 16:9 composition."
- **Purpose:** give engineers from CRUD backgrounds the core contrast of event sourcing at a glance: CRUD overwrites one current record; event sourcing appends every change to a log and derives the current state from it.
- **Where it goes:** in the first section, "Snapshot versus log", directly under the opening paragraph and before the comparison table.
- **Alt text:** "Illustration: on the left, a single form whose fields have been erased and overwritten, so only the latest values remain; on the right, a long ledger where each change is written as a new line under the previous ones and nothing is erased."
