## Gate 1: plan card

```
Plan: Sprint 46 retro: vote on four action ideas
Reader: the booking team (6 people)   Job: decide (vote), then operate (count)
Form: composed (traits: decision, status, live tweaking) - retro summary plus a ballot tool and a local tally tool
Outline: 1. What to do now (vote by Thursday 2026-11-06)  2. The four action ideas  3. Your ballot (pick, copy, paste in the channel)  4. Count the votes (facilitator pastes the channel lines, page totals them)  5. What went well  6. What to improve  7. References  8. Glossary
Interactivity: ballot (pick ideas, copy a vote line); tally tool that counts pasted vote lines; theme toggle. No shared or live totals: one HTML file cannot collect votes from six people.
References: 2 found (KT-948, RB-04), 2 resolved, 0 unresolved
```

Limit stated up front: the request "let everyone vote in the page and show the live totals" needs shared state, which a single file sent by Teams or email cannot hold. Each copy of the file is separate; a vote clicked in one copy is invisible to everyone else. The page therefore lets each person build a vote line and paste it in the team channel, and lets the facilitator paste all lines back in to get the totals. No hosting or publishing.
