    术语表

    CI 代理
    运行持续集成（CI）任务的构建机器。
    Docker-in-Docker
    在一个 Docker 容器内部再运行 Docker，CI 代理目前用这种方式启动测试所需的容器。
    Testcontainers
    一个测试库，在测试运行时自动启动并销毁所需的 Docker 容器（例如数据库），让集成测试不依赖预先搭好的环境。
