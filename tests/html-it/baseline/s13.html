What's new in p4m 8.4.0.1

A small update to 8.4.0.0. Appointment reminders are more reliable, booking search handles long result lists better, and the login form is easier to use with assistive technology.

Released 2026-11-04Previous 8.4.0.0Changes 6

For people using p4m

Changes you may notice in day-to-day booking and reminders.

  • FixedMoved appointments no longer send two reminder textsKT-972

    When an appointment was moved, the patient could get the reminder SMS twice. They now get one.

  • ImprovedReminders retry automaticallyKT-973

    If a reminder does not go out on the first try, p4m now retries it by itself.

  • ImprovedBooking search pages through results differentlyKT-971

    Booking search now uses keyset pagination. Moving through long lists of results should stay consistent when bookings are added or changed while you browse.

  • AccessibilityLogin form fields have visible labelsKT-975

    Each field on the login form now shows a label, which helps screen reader users and anyone who loses track of a field once they start typing.

For people running p4m

Deployment and internal changes. No visible effect for users is expected.

  • PlatformWildFly upgraded to 36.0.1KT-974

    The application server is now WildFly 36.0.1. Check your deployment against this version before upgrading.

  • InternalError handling code reorganisedKT-976

    The ExceptionMappers were refactored. This is a code cleanup with no intended change in behaviour.
