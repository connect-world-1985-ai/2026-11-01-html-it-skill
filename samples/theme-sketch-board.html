    What stays the same in every theme

    • The page structure: lede first, table of contents on wide screens, references and glossary at the end.
    • Light and dark: each theme follows the reader's system setting, and the toggle in the page header overrides it.
    • Colours come only from theme tokens, so a page switches theme by changing one attribute.
    • System fonts with Chinese fallbacks; nothing is loaded from the network.

    How the theme is chosen

    The agent recommends one theme on the plan card, from what the content is for, and you can pick another. The content type changes the layout, not the identity: a deck in Ivory and an explainer in Ivory still look related.
