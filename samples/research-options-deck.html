    Research review · 2026-10-30 report, presented 2026-11-03

    Ten ways to turn agent output into shareable HTML

    Recommendation: a skill that picks the page shape from the content and writes one self-contained HTML file. Three of the ten options fit that goal well, four fit part of it, and two belong inside applications, not in an email attachment. One more, Marp, gets a short note.

    Source: the team's research report research/report.md (in Chinese), comparison table and option details. Facts as fetched on 2026-10-30.

    Open with the goal: Raymond's agents write feature designs, pull request write-ups and code reviews, and the team wants one file it can open without an account. Then give the answer before the tour: the routing skill plus a single file. The rest of the deck is the evidence.

    Option 1 · Built into the agent

    Claude Artifacts

    What it is

    Claude puts standalone output (documents, decks, designs, dashboards, small interactive pages) beside the chat. Claude Code can publish a session's output as an interactive page, for example an annotated pull-request walkthrough. Design can export standalone HTML.

    Fit for single-file sharing

    Adapts well to the content. A single file is possible by exporting or downloading HTML. Native sharing usually needs a Claude account on the other side, so sending to any colleague means exporting the HTML.

    Fit: high Good for iterating; hand off the exported file.

    Key point: the native Share link needs a Claude account for everyone. Export is the way out.

    Option 2 · Skill

    Anthropic skills: frontend-design and web-artifacts-builder

    What it is

    frontend-design sets typography, colour and motion so pages avoid the default "AI look". web-artifacts-builder sets up a React, TypeScript, Vite, Tailwind and shadcn project and bundles it into one bundle.html.

    Fit for single-file sharing

    Aimed directly at "different look per subject" and "one HTML at the end". Skills move to other agents, because a skill is instructions and scripts loaded on demand. The file can be sent by email or chat.

    Fit: high The strongest ready-made design guidance; the React bundle is for real apps.

    Two roles: taste (frontend-design) and packaging (web-artifacts-builder). Most of our pages need only the first.

    Option 3 · Skill (an approach, not a product)

    Our own content-type routing skill

    What it is

    A skill that first decides what the content is (feature design, pull request, code review, and so on), loads a matching layout (a review gets severity cards, a file table and suggestions; a design gets problem, approach, sequence and acceptance), and writes one self-contained HTML file.

    Fit for single-file sharing

    Fits all four needs: adaptive layout, one file, sharing without accounts, and our three everyday content types. Controllable, versioned, and not tied to one vendor. Types can be added one at a time.

    Fit: high The report's main recommendation.

    This is what we built as html-it, with one change: it composes the page from the content's traits instead of a fixed list of types.

    Option 4 · Built into the agent

    Cursor Canvas and Grok Bot Pages

    What it is

    Canvas puts interactive output (dashboards, audits, reports) beside the chat and can publish a read-only link to the team on paid team plans. Grok Bot Pages turns output into a readable page; sharing can be by invitation, team, or anyone with the link (not on Enterprise).

    Fit for single-file sharing

    Adaptation depends on the prompt or skill. Both are mainly hosted views; a one-click "export one self-contained HTML" was not confirmed in the official documentation. Pages share well; Canvas sharing is limited to team members.

    Fit: medium Good for quick previews; not a file to send.

    Watch the "anyone with the link" option for sensitive content, and note that Enterprise turns it off.

    Option 5 · Built into the agent

    ChatGPT Sites

    What it is

    Sites builds, hosts and shares small websites and apps from a description in ChatGPT or Codex: resource hubs, dashboards, trackers. ChatGPT Canvas has been removed from current models; third parties date that to 2026-05-28, which the report could not confirm in the official release notes.

    Fit for single-file sharing

    A complete hosted sharing path, suited to a small site rather than an email attachment. A local single file is not the main path, and sharing depends on Sites permissions and workspace policy.

    Fit: medium Hosted URLs, not files.

    The Canvas removal date comes from third parties; treat it as unconfirmed.

    Option 6 · Open-source deck

    reveal.js

    What it is

    A mature HTML presentation framework (MIT licence, about 72,500 stars on GitHub). Markdown plugins, editor extensions and other tools turn Markdown into a deck that opens in a browser, with transitions and step-by-step reveals.

    Fit for single-file sharing

    Third-party tools export a standalone HTML with assets inlined, and it opens offline. The form is always slides, so it does not change the whole page layout per content type, but it suits a review walkthrough or a feature demo.

    Fit: medium The most dependable engine for slide walkthroughs.

    Star count from the GitHub page on 2026-10-30. The latest version was not re-checked.

    Option 7 · Open-source Markdown deck

    Slidev

    What it is

    Developer-oriented Markdown slides built on Vue (MIT licence, about 49,300 stars). slidev build produces a single-page app to host; it can export PDF, PPTX or PNG, and it has an official server for AI agents to read and write slides.

    Fit for single-file sharing

    Sources conflict. A third-party blog names a single-file flag, a pull request adding a standalone bundle was closed and rejected by the maintainers, and the official CLI documentation lists neither. The dependable path is to build a folder and host it.

    Fit: medium Great authoring; single-file export unconfirmed.

    Do not promise a single Slidev file to anyone until the official docs list the flag.

    Option 8 · Report generator

    Pandoc and Quarto

    What it is

    Pandoc converts documents; with --standalone --embed-resources it writes HTML with no external links. Quarto, built on Pandoc, does the same with embed-resources: true and adds a table of contents, code blocks and tab sets.

    Fit for single-file sharing

    Extremely mature for long documents and written reviews, and truly one file. It does not change the layout per content type unless we write and maintain several templates, which leads back to option 3.

    Fit: medium High for long reports, low for adaptive pages.

    Licences differ: Pandoc is GPL-2.0; Quarto says MIT from version 1.4, while GitHub shows no assertion. The report lists both.

    Option 9 · Generative UI library

    Vercel json-render

    What it is

    A generative UI framework: the model writes JSON within a predefined catalogue of components, and a client renderer draws it, with streaming through the Vercel AI SDK. Apache-2.0 licence, about 18,800 stars.

    Fit for single-file sharing

    Highly adaptive and easier to test than free HTML, but it is an application runtime. A single file would need a static export pipeline of our own.

    Fit: low For adaptive UI inside an app, not for files.

    Re-evaluate only if we build an agent UI into a product.

    Option 10 · Generative UI stack

    CopilotKit with A2UI

    What it is

    A front-end stack for agents. Generative UI connects to the A2UI component catalogue and a standard component library, and the AG-UI protocol renders the agent's UI actions in React, Angular and others. MIT licence, about 38,400 stars.

    Fit for single-file sharing

    Strong for copilots inside a product, weak for producing an HTML file to forward. A2UI 1.0 is still a candidate, so its interface may change.

    Fit: low Same answer as json-render.

    Mention Marp here if asked: simple Markdown decks, usually needs a second tool to inline images into one portable file.

    Decision

    What we did with it

    • Main path: option 3, built as the html-it skill, with taste from option 2.
    • Previews: Claude Artifacts or Cursor and Grok Bot Pages while iterating; the exported file for the handoff.
    • Talks: html-it's own deck mode, or reveal.js.
    • Long written reports: Pandoc or Quarto with embedded resources.
    • Not now: json-render and CopilotKit, until we build agent UI into a product.
