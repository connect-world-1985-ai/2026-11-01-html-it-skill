技术评估

    页面打开时为什么不连网

    结论：团队分享的 HTML 页面在打开时不发出任何网络请求。字体、样式、脚本和图片全部写进文件本身。原因有四：在中国大陆，常用的 CDN 被屏蔽或不稳定；CDN 脚本是与内部内容并排运行的第三方代码；CDN 地址日后可能失效；公司代理也可能拦截 CDN。确实需要某个库时，在生成页面时下载一个固定版本并内联进文件。

    技术评估，2026-11-03，供上海办公室和平台团队参考。依据：截至 2026 年年中的公开资料；未在中国大陆境内实测，以下是评估，不是测量结果。

    决定：页面打开时零网络请求。需要库时，由 agent 在生成页面时从 cdnjs 或 npm 仓库（中国大陆境内用 npmmirror）下载一个固定版本，内联进文件。读者的浏览器永远不会去取它。

    BootCDN、Staticfile国内镜像不信任国内速度快，但运营方就是 2024 年 polyfill.io 供应链攻击背后的实体。

    页面打开时发生了什么

    除了可达性，还有三个理由

    1. 安全。每个 CDN <script> 都是在内部内容（代码、事故、设计）旁边运行的第三方代码。polyfill.io 攻击正是这样扩散的。
    2. 持久。一年后从 Teams 旧消息里打开的页面依然能用；CDN 地址和版本可能消失。
    3. 代理。公司代理可能拦截 CDN。

    约 3 MB最坏情况：内联一个大型库，Teams 和邮件仍可发送
    约 200 KBChart.js，只在真正需要交互数据时内联
    • 手绘 SVG 代替 Mermaid（压缩后约 3 MB）。
    • 代码高亮在生成时直接写进 HTML，代替 highlight.js。
    • 图片以 data URI 嵌入；只有大量截图或视频才会让文件超过约 20 MB，这时改用多文件夹方式。

    决定与做法

    • 页面打开时零网络请求。html-it 技能的检查脚本 check_html.py 会让任何从网络加载脚本、样式、字体、图片或调用 fetch 的页面检查失败。
    • 需要库时，在生成页面时下载一个固定版本（cdnjs 或 npm 仓库；中国大陆境内用 npmmirror）并内联。
    • 不使用 BootCDN、Staticfile。
    • 普通超链接（<a href>）不受限制：读者点击时才访问，页面本身不依赖它。

    待确认：以上可达性来自截至 2026 年年中的公开资料，未在中国大陆境内实测。建议上海办公室的同事打开一个示例页面，确认没有延迟。

    术语

    CDN
    内容分发网络：托管常用文件（如 JavaScript 库和字体）的服务器网络，许多网站从同一处加载这些文件。
    ICP 备案
    在中国大陆提供网站服务所需的工信部备案。没有备案，境内节点不能合法提供服务。
    供应链攻击
    攻击者篡改许多网站共同依赖的第三方代码或服务，从而一次影响所有使用它的网站。2024 年的 polyfill.io 事件是一例。
    data URI
    把文件数据本身写进 URL 的方式（例如 data:image/png;base64,…），不需要单独的文件或下载。base64 编码会让数据变大约 33%。
    SVG
    可缩放矢量图形：用文字描述的图形，直接写在 HTML 里，放大不失真，可随浅色或深色主题变化。
